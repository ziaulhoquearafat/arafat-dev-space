## ✨ Key Features

- **Advanced GSAP Animations:** Custom scroll-triggered micro-interactions, stacked card effects, and staggered entry animations for a top-tier user experience.
- **Full-Stack Admin Dashboard:** A secure, custom-built CMS to seamlessly manage projects, case studies, and blog posts without touching the database.
- **Dual Content Engines:** \* _Projects:_ Markdown-based editor (`react-markdown`) for highly technical, code-heavy case studies.
  - _Blogs:_ WordPress-style classic rich text editor (`react-quill-new`) with Tailwind Typography for beautifully formatted articles.
- **Smart Media Management:** Integrated with Cloudinary for automatic image compression, WebP conversion, and optimized delivery.
- **High-End UI/UX:** Built with Tailwind CSS v4 and Shadcn UI, featuring glassmorphism, glowing accents, and a cohesive dark/modern aesthetic.
- **Seamless Contact System:** Direct email integration using Nodemailer for instant client communication.

## 🛠️ Tech Stack & Architecture

**Frontend:**

- Next.js (App Router)
- React 19
- Tailwind CSS v4 & @tailwindcss/typography
- GSAP & @gsap/react (Animation Engine)
- Lucide React (Icons)
- React Hook Form + Zod (Validation)

**Backend & Database:**

- Next.js Route Handlers (API)
- MongoDB & Mongoose (Schema validation & data modeling)
- Cloudinary (Media CDN)
- Nodemailer (Email service)

## ⚙️ Environment Variables

To run this project locally, create a `.env.local` file in the root directory and add the following variables:

```env
# Database
MONGODB_URI=your_mongodb_connection_string

# Cloudinary (Image Optimization & Storage)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# Authentication / Security (If applicable)
JWT_SECRET=your_jwt_secret

# Contact Form Email (Nodemailer)
EMAIL_USER=your_gmail_address
EMAIL_PASS=your_gmail_app_password
```
